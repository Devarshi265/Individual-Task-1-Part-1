# Case Study 2026 — Banking Data Science

This repository contains the Jupyter Notebook for my Case Study 2026 assessment.

## Project Overview

The project applies machine learning to two banking-related datasets:

- **Bank Marketing Dataset**
- **Default of Credit Card Clients Dataset**

Two classification algorithms were used:

- Logistic Regression
- k-Nearest Neighbours (kNN)

The models were evaluated using accuracy, precision, recall and F1-score.

## Key Analysis

The Bank Marketing dataset was used to investigate customer subscription to term deposits, while the Credit Card dataset was used to analyse payment default risk.
The analysis includes data preparation, exploratory analysis, machine learning, model evaluation and interpretation of key features.
